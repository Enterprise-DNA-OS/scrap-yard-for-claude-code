# add-contract

Run `npm run scrap -- add-contract --code= --buyer= --grade= --tonnes= --price=<per tonne> --deliver-by=YYYY-MM-DD [--currency=NZD] [--notes=]`. Fill in the operator's values. Add `--json` when you need every field.

Price per tonne in the contract currency.

Nothing here sends a message, pays anyone or contacts anyone.
