# add-grade

Run `npm run scrap -- add-grade --code= --name= --family=ferrous|non_ferrous|copper|vehicle|battery [--copper=0-100]`. Fill in the operator's values. Add `--json` when you need every field.

Set copper content honestly: it decides the Victorian cash rule and the holds.

Nothing here sends a message, pays anyone or contacts anyone.
