# add-line

Run `npm run scrap -- add-line <ticket> --grade= --gross= [--tare=] [--price=] [--vin=] [--vrego=] [--item=] [--photo] [--desc=]`. Fill in the operator's values. Add `--json` when you need every field.

Adds a line to an open ticket at the board price.

Nothing here sends a message, pays anyone or contacts anyone.
