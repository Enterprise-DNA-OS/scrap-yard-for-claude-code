# add-seller

Run `npm run scrap -- add-seller --code=P20 --name= [--kind=public|trade] [--business=] [--business-no=] --address= [--phone=] [--email=] [--dob=YYYY-MM-DD] --id-type= --id-number= [--id-expires=YYYY-MM-DD]`. Fill in the operator's values. Add `--json` when you need every field.

Name, address and photo ID are required. In New Zealand also record date of birth.

Nothing here sends a message, pays anyone or contacts anyone.
