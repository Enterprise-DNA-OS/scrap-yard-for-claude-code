# attention

Run `npm run scrap -- attention`. Fill in the operator's values. Add `--json` when you need every field.

Lead with breaches and anything with days left under 7. For a compliance row, name the rule and its source. For an unpaid ticket, say who and how much. Offer the matching fix: update-seller for missing ID, a draft statement, a buyer update for a short contract.

Nothing here sends a message, pays anyone or contacts anyone.
