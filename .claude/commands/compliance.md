# compliance

Run `npm run scrap -- compliance`. Fill in the operator's values. Add `--json` when you need every field.

Report as a table: rule, record, detail, source. Breaches first. For each, the fix: record the missing ID, add the VIN, release nothing early, renew the licence. Read docs/compliance.md and say if a rule looks out of date. Nothing here is legal advice.

Nothing here sends a message, pays anyone or contacts anyone.
