# contracts

Run `npm run scrap -- contracts`. Fill in the operator's values. Add `--json` when you need every field.

Lead with any contract marked short. Say how many tonnes must be bought in and by when, and offer /draft-buyer-update.

Nothing here sends a message, pays anyone or contacts anyone.
