# day-end

Run `npm run scrap -- day-end`. Fill in the operator's values. Add `--json` when you need every field.

Run at close of day for each yard. Total tonnes in, paid by method, and what is still open. Any cash total at a NSW or Victorian yard is a question for the yard manager.

Nothing here sends a message, pays anyone or contacts anyone.
