# draft-register

Run `npm run scrap -- draft-register [--from=YYYY-MM-DD] [--to=YYYY-MM-DD] [--site=]`. Fill in the operator's values. Add `--json` when you need every field.

Writes a CSV to drafts/. Hand it to whoever deals with the police or the regulator; this system sends nothing.

Nothing here sends a message, pays anyone or contacts anyone.
