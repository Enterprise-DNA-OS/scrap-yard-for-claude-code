# log

Run `npm run scrap -- log <seller> --body="..." [--kind=note|call|visit|email|police] [--on=YYYY-MM-DD]`. Fill in the operator's values. Add `--json` when you need every field.

Use --kind=police for a police enquiry, so it shows on the seller record.

Nothing here sends a message, pays anyone or contacts anyone.
