# margin

Run `npm run scrap -- margin`. Fill in the operator's values. Add `--json` when you need every field.

Average buy price against average sell price per tonne for each grade over 30 days. A grade with buys and no sales is stock building up.

Nothing here sends a message, pays anyone or contacts anyone.
