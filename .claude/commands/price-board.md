# price-board

Run `npm run scrap -- price-board`. Fill in the operator's values. Add `--json` when you need every field.

Group by yard. Flag any grade whose price has not moved for 21 days: the market has. To change a price, use /set-price.

Nothing here sends a message, pays anyone or contacts anyone.
