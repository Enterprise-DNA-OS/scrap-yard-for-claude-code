# release

Run `npm run scrap -- release <ticket>[/<line>] [--on=YYYY-MM-DD]`. Fill in the operator's values. Add `--json` when you need every field.

Refused while a hold runs. Say the hold date when it is refused.

Nothing here sends a message, pays anyone or contacts anyone.
