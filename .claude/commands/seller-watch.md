# seller-watch

Run `npm run scrap -- seller-watch`. Fill in the operator's values. Add `--json` when you need every field.

A pattern is not proof. Show the seller history with /seller, and if the yard manager agrees, log a note or ban with /update-seller. Police contact is a person's decision, never this system's.

Nothing here sends a message, pays anyone or contacts anyone.
