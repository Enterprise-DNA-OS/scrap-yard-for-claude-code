# set-price

Run `npm run scrap -- set-price --site= --grade= --price=<dollars per tonne> [--kind=public|trade] [--from=YYYY-MM-DD]`. Fill in the operator's values. Add `--json` when you need every field.

Prices are dollars per tonne. Public and trade boards are separate.

Nothing here sends a message, pays anyone or contacts anyone.
