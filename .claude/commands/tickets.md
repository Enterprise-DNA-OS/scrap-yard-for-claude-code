# tickets

Run `npm run scrap -- tickets`. Fill in the operator's values. Add `--json` when you need every field.

Filter with --site, --status, --seller or --days. Summarise counts and dollars before listing.

Nothing here sends a message, pays anyone or contacts anyone.
