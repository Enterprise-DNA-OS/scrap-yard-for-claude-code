# update-seller

Run `npm run scrap -- update-seller <seller> [--address=] [--dob=] [--id-type=] [--id-number=] [--id-expires=] [--phone=] [--ban --reason=] [--unban]`. Fill in the operator's values. Add `--json` when you need every field.

Ban needs a reason, which is kept in the seller notes.

Nothing here sends a message, pays anyone or contacts anyone.
